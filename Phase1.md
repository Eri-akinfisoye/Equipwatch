## Task Set 1 — Equipment Profiles and Data Generation

**Task 1.1 — Equipment Profiles**
Define a dictionary called `EQUIPMENT_PROFILES` that stores the normal operating parameters for all 5 machines. Each machine should have the following keys:
- `current_mean`, `current_std`
- `temp_mean`, `temp_std`
- `vibration_mean`, `vibration_std`
- `section`

Use the values from the table below:

| Equipment | Section | Current mean | Current std | Temp mean | Temp std | Vibration mean | Vibration std |
|---|---|---|---|---|---|---|---|
| MOTOR_1 | Electrical | 4.5 | 0.2 | 67.0 | 1.5 | 2.3 | 0.15 |
| MOTOR_2 | Electrical | 5.1 | 0.3 | 72.0 | 2.0 | 2.8 | 0.20 |
| PUMP_1 | Mechanical | 3.8 | 0.15 | 58.0 | 1.0 | 1.9 | 0.10 |
| PUMP_2 | Mechanical | 4.2 | 0.25 | 63.0 | 1.5 | 2.1 | 0.12 |
| COMPRESSOR_1 | Mechanical | 6.3 | 0.4 | 81.0 | 2.5 | 3.5 | 0.25 |

**Task 1.2 — Single Machine Generator**
Write a function called `generate_readings(equipment_name, n_readings)` that:
- Takes equipment name and number of readings as parameters
- Looks up that equipment's profile from `EQUIPMENT_PROFILES`
- Generates `n_readings` rows of normally distributed current, temp, and vibration using `np.random.normal()`
- Adds a `timestamp` column using `pd.date_range()` starting `2026-01-01` at 5 minute intervals
- Adds an `equipment` column and a `section` column pulled from the profile
- Returns a DataFrame

**Task 1.3 — Fault Injector**
Write a function called `inject_fault(df, fault_fraction=0.2)` that:
- Takes a DataFrame and a fraction as parameters
- Calculates how many rows the last `fault_fraction` represents
- Ramps current up by 2.5A, temp up by 18°C, and vibration up by 3.2mm/s across those rows using `np.linspace()`
- Returns the modified DataFrame

## Task Set 2 — Full Fleet Simulation

**Task 2.1 — Fleet Generator**
Write a function called `simulate_fleet(n_readings=200)` that:
- Calls `generate_readings()` for all 5 machines
- Injects faults into `MOTOR_1` and `PUMP_2` only using `inject_fault()`
- Combines all 5 DataFrames into one using `pd.concat()`
- Resets the index
- Returns the combined DataFrame

**Task 2.2 — Export to CSV**
At the bottom of `simulator.py`, add a block that:
- Only runs when the file is executed directly (use `if __name__ == '__main__':`)
- Calls `simulate_fleet()` and stores the result in a variable called `df_raw`
- Prints the shape of `df_raw` and its first 5 rows
- Exports `df_raw` to `equipwatch/data/simulated_readings.csv` with `index=False`
- Prints a confirmation message when done

> Tool note: CSV is the handoff format between `simulator.py` and `processor.py` in Phase 2. PostgreSQL comes in Phase 2 — `simulator.py` does not connect to the database.

## Task Set 3 — Validation

**Task 3.1 — Profile Check**
After running `simulator.py` and generating the CSV, open a separate notebook or script and:
- Load `simulated_readings.csv` into a DataFrame
- Group by `equipment` and print the mean and standard deviation of current, temp, and vibration for each machine
- Confirm the values are close to the profiles in `EQUIPMENT_PROFILES`

**Task 3.2 — Fault Check**
Still in the same notebook:
- Filter to `MOTOR_1` only and plot current over time using matplotlib
- Filter to `PUMP_2` only and plot current over time
- Both charts should show a visible upward ramp in the last 20% of readings
- Filter to `MOTOR_2` as a control — it should show flat, stable readings with no ramp

**Task 3.3 — Null Check**
- Run `df.isna().sum()` on the full loaded DataFrame
- Confirm there are zero null values across all columns
- Print the count of readings per equipment using `value_counts()` and confirm all 5 machines have the same number of rows
